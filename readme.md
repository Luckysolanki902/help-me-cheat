# Key Shortcuts and Their Functions

### For Quiz Mode
- **Ctrl+I**: Captures a screenshot of the current screen, extracts text, sends it to Gemini AI for processing, and sends the response via WhatsApp. The extracted text is also copied to the clipboard.

- **Ctrl+W**: To stop the program
